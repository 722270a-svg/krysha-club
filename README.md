# КРЫША — публичное приложение

Адаптивное веб-приложение для гостей клуба в Якутске. Развёртывание через GitHub Pages (Settings → Pages → Deploy from a branch → main / root). Бронирование и онлайн-регистрация пока доступны только через связь с клубом. Не хранит пароли, не делает вид, что заявки отправляются. Для полноценных сервисов необходимы backend, авторизация, подтверждённые материалы клуба и интеграции.
